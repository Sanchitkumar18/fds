# CWRU-PG — datasheet

A physics-guided dataset **derived** from the original CWRU Bearing Data Center recordings.
It contains no synthesised signals: every window is cut from a real recording. It is
generated by `scripts/build_derived_dataset.py` in under a minute on a laptop CPU.

## Source
- 40 CWRU 12 kHz drive-end recordings, SKF-6205 bearing:
  - Normal: 97–100.
  - Inner race: 105–108, 169–172, 209–212.
  - Ball: 118–121, 185–188, 222–225.
  - Outer race @6:00: 130–133, 197–200, 234–237.
  - Fault diameters 0.007/0.014/0.021 in; motor loads 0–3 hp.
- The normal baselines are 48 kHz and are decimated ×4 to 12 kHz.
- The recorded shaft speed of each file is used.

## Contents

### `cwru_pg.npz` — 4,643 real windows
Window settings: 2048 samples, 50 % overlap.

| Key | Content |
|---|---|
| `stft` | 64×64 log-magnitude STFT, float16 |
| `stats4` | RMS, kurtosis, crest factor, skewness |
| `handcrafted12` | 12 time/frequency features |
| `raw_spec`, `env_spec` | raw and squared-envelope power spectrum, 0–1 kHz, 5.9 Hz bins (`spec_freqs`); envelope band 1–5.5 kHz |
| `label`, `class_names` | healthy / inner / outer / ball |
| `severity_in`, `load_hp`, `shaft_hz` | fault diameter, motor load, recorded shaft speed |
| `recording`, `start` | provenance; the raw window is `signal[start:start+2048]` |
| `char_freqs_bpfo_bpfi_bsf` | the window's characteristic frequencies |
| `evidence` | per-fault-type physical evidence ē (σ = 5 Hz, H = 3); healthy column is 0 |
| `evidence_pred` | fault type chosen by the evidence alone |
| `split_indist`, `split_xload`, `split_single` | train/val/test/unused under the three leakage-free protocols |

### Other files
- **`cwru_pg_index.csv`** — one row per window with the provenance, split, statistics and evidence columns.
- **`stress_<variant>.npz`** — the ten 3 hp recordings under seven conditions:
  - additive white noise at 10/5/0/−5 dB;
  - time-warp ×0.95 or ×1.05;
  - ±5 % speed fluctuation at 0.5 Hz.

  Each file stores the same inputs, spectra and evidence; 8,187 windows in total.
- **`summary.json`** — counts and evidence accuracies.

## Leakage policy
Splits are formed on the continuous recordings before windowing. Windows in guard gaps are
marked `unused`. No two windows in different splits of a protocol share a sample.

## Measured annotation quality
Envelope evidence identifies the fault type of 66.0 % of the faulty windows:

| Breakdown | Evidence accuracy |
|---|---|
| Inner / outer / ball | 74.4 / 72.7 / 50.8 % |
| 0.007 / 0.014 / 0.021 in | 82.7 / 48.3 / 66.8 % |
| 0 / 1 / 2 / 3 hp | 68.8 / 66.5 / 64.4 / 64.1 % |

## Caveats
- The speed variants are emulated by time-warping. This also scales the structural resonances.
- The evidence is a kinematic annotation, not ground truth. Use `label` for ground truth.
